# Changelog

All notable changes to this project are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.4.3] - 2026-11-02

### Fixed
- A configured direction disappearing (e.g. 9 → Westbahnhof S U) whenever the next tram was a short run
  to the depot: Wiener Linien rows are now grouped by direction and named after the destination most
  upcoming trams have; if none goes to the configured destination, the row takes that line's other
  unconfigured direction instead of vanishing

## [1.4.2] - 2026-11-02

### Fixed
- Refresh seconds briefly showing 11s (10s → 11s → 9s) when the timing estimates came out a little over the
  refresh interval: the countdown never goes above `refresh_seconds` now

## [1.4.1] - 2026-11-02

### Changed
- The red LIVE dot slowly blinks (fades out and back in every 2 s, `LIVE_PULSE_S`)

### Fixed
- Parts of the screen flashing yellow for a moment: Pillow marked unchanged pixels with a "transparent"
  palette colour, which the Kraken ignores and paints in that colour. GIFs are now saved without transparency
- Refresh seconds stuck at "1s" or jumping (3s → 9s): the countdown now runs to the moment the next GIF
  usually appears, so it goes 1s → 10s. The Kraken also plays frames slower than the 250 ms requested, so
  frames are drawn `lcd_frame_ms` apart (new option, measured with the new `calibrate` command)

## [1.4.0] - 2026-11-02

### Added
- Up to 6 rows (more than 4 are drawn smaller)
- S-Bahn rows from ÖBB: `oebb_station` in a `[[departures]]` entry
- Disruptions: when a line can't run (not lift/escalator outages), its Wiener Linien disruption text scrolls
  through in turns with the direction name (`disruptions`, colour `info`)
- New look by default: clock at the top with "Linie" / "Abfahrt in Minuten" column labels (`header`),
  "● LIVE" plus a refresh ring next to the clock (`live_in_header`), LED dot digits for minutes and line
  numbers (`led_numbers`), white outlined line badges (`badge_style`, `badge`, `badge_text`), Arial (`font`).
  `header = "station"`, `led_numbers = false` and `badge_style = "fill"` bring back the old look
- Long direction names scroll slowly instead of being cut off
- Options `now_text`, `now_style` (text / yellow dot / yellow block), `soon_minutes`, `flash_blink`,
  `flash_fade_in`, `flash_fade_out`, `sign_font` (your own LED-style font in `fonts/`, not included), and
  the colours `flash`, `soon`, `sign`

### Changed
- "jetzt"/"now" appears only while the tram is expected at the stop (20 s before it really leaves,
  `NOW_WINDOW_S`) instead of for the whole last minute; until then the countdown shows 1'. When a tram
  really leaves is learned per line and direction: Wiener Linien drops a vehicle from the data once it has
  left, and the average difference to the estimate is kept in `departure_offsets.json`

### Fixed
- Flicker and countdowns briefly going back up: each GIF ran out about 1 s before the next one arrived, so
  the Kraken looped back to the start of the cycle. GIFs now run past the expected next upload
- Countdowns jumping between two minutes (4' → 5' → 4') because the live estimates wobble by ±30 s:
  a countdown now goes up only once the new time is 30 s into the higher minute
- Whole screen going blank for a moment every few refreshes: every frame had its own palette, so a GIF was
  ~600 KB. All frames now share one palette (~35 KB)

## [1.3.0] - 2026-11-02

### Added
- `ExitWienerLinienDisplay.exe`: double-click to stop the display cleanly. Its icon is the launcher icon with
  a cross, generated by `launcher\make_exit_icon.py`
- `launcher\build.ps1` builds both `.exe` files, and `-Desktop` copies both

### Fixed
- Launcher copyright showed as `Â©` in the file properties

## [1.2.0] - 2026-11-02

### Added
- Desktop launcher `RunWienerLinienDisplay.exe` (source in `launcher/`, built with `launcher\build.ps1`):
  closes NZXT CAM, restarts a running display cleanly, runs hidden and logs to `display.log`
- `python tram_lcd.py stop`: asks a running display to exit between uploads

### Fixed
- Uploads failing with "missing messages" while other software (e.g. SignalRGB) talks to the Kraken

## [1.1.0] - 2026-11-02

### Added
- **Any station, any line:** settings now live in `config.toml` instead of the code
- Interactive setup wizard: `python tram_lcd.py setup` (station search, line picker, language, tilt, footer)
- Commands `search`, `lines` and `preview` (preview renders a frame without a Kraken)
- `--config` option to switch between config files
- Line colours for U1–U6, plus colours by vehicle type for bus, night bus, S-Bahn and WLB
- English labels (`language = "en"`)
- Configurable title, footer text and clock/footer colours
- Rows stay centred when fewer than 4 are shown; long station names shrink to fit
- Support for the Kraken 2023 / 2024 models liquidctl knows (untested), with a static-image fallback for
  firmware that doesn't accept GIFs

### Changed
- Requires Python 3.11+ (uses `tomllib`)
- liquidctl is only imported when the display runs, so `setup`, `search`, `lines` and `preview` work
  without touching USB

## [1.0.0] - 2026-11-02

### Added
- Live departures for lines 42 and 9 at Vinzenzgasse on the NZXT Kraken Z3 LCD
- One animated GIF per refresh cycle (10 s), with frames drawn for the moment they are shown
- Red notification box when a countdown changes: one blink, then a 3 s fade
- Blinking "jetzt" on a green background
- "LIVE · NEU IN n S" refresh countdown
- Tilt compensation (`TILT_FIX`) for pumps mounted at an angle
- Runtime workarounds for liquidctl / WinUsbCDC on Windows (see `docs/TROUBLESHOOTING.md`)
- Automatic reconnect after USB or network errors
